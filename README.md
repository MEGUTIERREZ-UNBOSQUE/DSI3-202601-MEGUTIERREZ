Miguel Elías Gutiérrez García

Sitio web personal desarrollado en HTML5 y CSS3 como proyecto académico.  
Presenta información sobre mi perfil, educación, intereses y un formulario de contacto.

Descripción

Este proyecto consiste en una página web estática que muestra:

- Información personal
- Formación académica
- Intereses y tecnologías en aprendizaje
- Información sobre mascotas
- Formulario de contacto
- Recursos multimedia (video y audio)

Fue desarrollado como práctica de estructura semántica en HTML y estilos con CSS.

Tecnologias

- HTML5 (estructura semántica: header, nav, article, section, aside, footer)
- CSS3 (estilos personalizados, tipografías y diseño visual)
